재귀를 이용해서 풀이했다.

라이언의 화살 현황을 재귀를 도는데 탐색 횟수를 줄이기 위해 라이언 화살 배열의 값을 1씩 올린다거나 어피치보다 특정 점수에 더 많은 화살을 이미 쐈는데 n 을 다 소진할 때까지 해당 점수를 추가 탐색하는 것을 하지 않았다.

현재 인덱스의 어피치가 쏜 화살 갯수보다 1을 더하고 n 은 그만큼 빼준 다음에 재귀를 이어나간다. n 이 0보다 작아지지 않도록 하기 위해 무조건 어피치가 쏜 화살 갯수에 1을 더하는 방식이 아니라 남은 n과 비교해서 둘 중 최소값을 적용했다.
